# 本地网页工作台

## 恢复、业务测试、开销与交付包

在本地任务详情点击“从完成的检查点恢复任务”。相同源任务重复点击返回同一个恢复任务；若恢复任务也失败，请进入该新记录再恢复。已完成规划/生成可复用，审批、构建及后续检查会重做。旧任务没有检查点时从头规划，旧费用不可凭空补回。

网页“交付检查与执行预算”配置实际操作与结果断言。交付模式必须测试通过；原型模式不能下载交付包。继续修改时留空业务步骤沿用原测试。业务脚本使用 Node Playwright：常规安装可直接使用 `playwright` 包；非标准路径设置 `FACTORY_PLAYWRIGHT_MODULE`，系统 Chrome 路径设置 `FACTORY_BROWSER`，Node 非 PATH 时设置 `FACTORY_NODE`。不配置运行时会明确失败，不自动下载依赖。

“模型单价与费用口径”填写精确模型名及当前账户输入/输出单价，后续新任务采用配置快照。金额预算需匹配币种；未知费用不能按零处理。运行时显示本次和恢复链估算，“本地任务”显示全部已记录估算。统计不是供应商账单，也不包含人工、托管及未记录旧任务成本。

通过业务测试与人工验收后，在详情下载交付包。包内说明包含安装、构建、启动及正式上线前配置。导出不启动生产服务；源码或证据被改动时需重新验证。截图保存在 `.factory/runs/<id>/business/`。

升级前备份 SQLite。新版增加 recovery_points、recoveries、prices 表；生产入口以 `.factory/web.lock` 保证单进程。服务崩溃不需要删除锁文件，OS 会释放锁。不要绕过锁运行第二个后端。

## 继续修改已有项目

点击“本地任务”，打开有源码的结束任务，选择“继续修改这个项目”。输入本次变化及新增要求，原需求和未涉及文件自动保留。若已有可用版本，需从该版本开始。方案和预览仍需确认。

在“项目版本与修改差异”查看版本。只有检查和人工验收通过的版本可以设为当前版本；恢复不部署、不覆盖旧目录。原目录特性文件被手改时会阻止继续修改，请先备份并整理，不会自动合并外部编辑。

升级前停止后端，备份 `.factory/history.sqlite3`、`.factory/runs/` 和 `generated/`。新版在事务中增加项目索引表，旧任务原文保留。回退软件前停止服务，恢复升级前数据库备份；升级后的新记录另行导出保留。仅支持一个后端进程使用同一库。

在项目根目录运行 `.\.venv\Scripts\python.exe -m orchestration.web`，打开 http://127.0.0.1:8765 。端口冲突时使用 `--port 8766`。停止服务使用 Ctrl+C。

模型凭据通过本地 `.env` 或环境变量配置，不从网页上传。可使用 `FACTORY_MODEL` 或 `FACTORY_PLANNER_MODEL` 等设置账户可用模型；这些配置在 Agent 实例化时读取。

运行失败后，在页面下载报告，检查 `errors`、`build_log`、`acceptance_report`。`implemented` 仅表示有代码证据，`missing` 或 `uncertain` 会阻止验收。预览只在等待人工验收期间运行，批准或拒绝后停止。

报告包含用户需求和生成源码，默认只在 `.factory/` 本地保存，不要未经检查公开。浏览器页面刷新可以继续查询当前任务；Python 服务重启后只保留磁盘报告，不会恢复执行。

GitHub 网络不可用不影响本地网页开发；远程发布需在网络恢复后从升级分支创建 PR。

## DeepSeek 本地环境

检测到 `DEEPSEEK_API_KEY` 且没有 Anthropic 凭据时自动使用 DeepSeek。多凭据环境使用 `FACTORY_PROVIDER=deepseek` 明确选择。默认 `deepseek-chat`，可用 `DEEPSEEK_MODEL` 覆盖。凭据只从进程环境或本地 dotenv 读取，不写入报告或代码。切换后需重启网页服务。

## 方案确认界面

默认展示产品摘要、用户要求、核心功能和本次范围。使用场景、成功标准、风险、实施计划与技术方案按需展开。完整 JSON 仍可在“完整运行报告”查看和下载；轮询不会重置已展开的详情。

## 界面设计

采用 Arctic editorial 视觉：冷灰全屏首屏、原创冰质素材、大字叠层，以及无卡片的需求和审批排版。首屏移除视角缩略图，以系统主题、雕塑和开始创作为重点。雕塑支持点击、横向拖动和左右方向键切换视角；桌面用银白三角光标替代系统箭头。触摸使用原生交互；减少动态效果时关闭过渡、视差和拖尾。仍使用原有 HTML/CSS/JavaScript 和 Python 服务，无新增运行时依赖。素材与生成提示词见 `orchestration/assets/README.md`。先前绿色 Figma 稿是历史版本，不代表当前页面。

静态图片路由需要新版本 Python 服务；仅刷新网页不能更新已加载的后端代码。已有任务时先完成当前审批，或在独立端口启动新版（例如 `--port 8771`），避免影响旧任务。

## 浏览器回归检查

测试需要 Playwright（开发工具，不是工作台运行依赖）及 Chromium/Chrome。启动本地工作台后运行：

```powershell
# Playwright 模块不在标准 node_modules 时指定安装目录
$env:PLAYWRIGHT_MODULE='<Playwright 模块目录>'
# 使用已安装的 Chrome；留空则使用 Playwright Chromium
$env:FACTORY_BROWSER='C:/Program Files/Google/Chrome/Application/chrome.exe'
$env:FACTORY_TEST_URL='http://127.0.0.1:8771'
node tests/web-ui-smoke.cjs
```

脚本在独立浏览器中拦截全部 job API，不会调用模型、提交真实任务或批准已有任务。截图保存于 `.factory/visual-review/`，包含四种尺寸和长方案状态。检查初始页图片与溢出、视角切换、减少动态效果、原始指令、文本安全、审批重试和报告下载。

Windows 沙箱的系统临时目录不可写时，可给 pytest 指定项目内尚未使用的临时目录：

```powershell
.venv/Scripts/python.exe -m pytest -q --basetemp=.factory/pytest-review-new -o cache_dir=.factory/pytest-cache
```

## 首屏使用说明

点击“了解如何使用”打开六章说明：需求输入、方案审批、执行检查、预览验收、报告与恢复、能力边界。章节可展开；关闭按钮或 Escape 返回入口，“明白了，开始写需求”聚焦需求框。阅读说明不会调用模型。光标仅在鼠标定位成功后隐藏原生箭头，键盘操作、离开窗口或失焦时恢复原生指针。

首屏恢复雕塑与右下角步骤说明联动：点击、横向拖动或左右方向键切换雕塑时，同步展示需求、方案、实现、验收说明。也可直接点四个文字步骤。没有缩略图；完整说明仍可按需打开。此处是使用引导，不是当前任务进度。

## 宽屏与矮窗口

桌面首屏使用分行布局，为主视觉、左右文案和底栏各自预留空间。大字和雕塑同时受窗口高度与尺寸上限约束；矮窗口允许自然滚动。浏览器回归覆盖 11 个尺寸（2558×1358 至 390×844），包括宽矮窗口和缩放后常见的 CSS 视口，并断言大字与两侧说明不重叠。

## 本地任务存储与迁移

点击导航“本地任务”打开任务列表弹窗，主页面不展示历史列表。点选记录查看原始需求、方案、审批反馈、执行日志、生成源码与检查报告；返回列表或按 Escape 退出详情。桌面三角光标放大约 25%，保留原有粒子拖尾。

任务数据由 Python 后端写入 `.factory/history.sqlite3`，浏览器仅通过 API 读取，不依赖浏览器缓存。每次状态检查点、日志和审批都会保存；服务重启后，未完成任务标记为“已中断”，不会自动重放审批或继续执行。启动时幂等导入 `.factory/runs/*/report.json`，旧报告未保存过的日志无法补回。已知模型凭据会在存储前脱敏。

历史预览需要原生成目录、依赖、通过的构建和安全检查。启动预览不调用模型，每次只运行一个历史预览，30 分钟后自动停止；目录或依赖缺失时显示原因，已保存源码仍可查看和下载。

迁移时先停止后端，备份数据库以及 `.factory/runs/` 和 `generated/`，再迁移到服务器。当前生成目录保存为绝对路径，迁移后需调整记录中的目录路径再重开预览。当前版本面向单个本机后端进程；服务器公开访问前需另行配置身份认证和访问控制，不直接暴露本地开发服务。

## 说明书滚动与鼠标效果

说明弹窗使用独立顶部栏与正文滚动区，只有正文滚动；顶部不再吸附覆盖正文。关闭、Escape 与焦点返回行为保持。桌面三角光标保留精确尖端，移动时产生银白/淡冰蓝粒子，360–580ms 消散，最多 42 粒；停下后停止绘制循环。触摸和减少动态效果模式禁用粒子，失焦、缩放与离开页面时清理。浏览器回归验证展开所有章节后的中段/底部滚动及粒子产生、消退。
