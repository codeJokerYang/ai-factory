# 检查点恢复、业务验证、开销与本地交付

## 已实现

### 中断恢复

- 完成步骤保存独立检查点；失败步骤中的临时状态不会覆盖成功检查点。
- 已失败或中断任务可显式恢复到新任务，旧记录不可变；恢复关联用唯一键防止重复点击创建多次执行。
- 可复用完成的需求、方案、拆解和生成产物；重新确认方案、构建、审查、业务测试及预览审批。未完成步骤重新执行，不继续半次模型请求。
- 当前项目版本已变化时拒绝恢复过期任务。被人工拒绝的任务需要修改需求后提交。
- 旧记录没有检查点时从规划开始；不会编造恢复进度。模型预算和用量账本跨恢复累计。
- 同一数据库使用操作系统文件锁，阻止第二个本地后端启动后误将任务标记中断。进程退出或崩溃自动释放锁；当前仍为单 worker。

### 真实业务验证

网页默认选择交付验证；原型探索保留兼容。业务步骤作为数据传入，不接受任意测试 JavaScript。

```text
访问 /
填写 姓名=张三
点击 保存
应显示 保存成功
刷新
字段 姓名=张三
```

支持站内访问、按可访问名称点击按钮/链接、按 label 填写输入、可见文本断言、输入值断言和刷新。每个场景有独立浏览器上下文，在 1440 和 390 宽度分别执行。最多 10 个场景，每个 20 步，每个至少一个结果断言。网页输入目前提供单场景编辑；通过 API 提交的多场景可沿用。

测试检查页面错误、站内页面 HTTP 状态、关键结果及横向溢出，记录步骤数、错误、截图和截图哈希。浏览器 HTTP 请求限制为同源，WebSocket 关闭；外部业务服务需要后续受控集成配置。浏览器不是生成代码的操作系统沙箱，应用后端仍在本机执行。

缺少浏览器运行时、场景失败、报告缺失或结果数量不符时禁止交付验收。业务通过只代表这些配置场景通过，不代表所有业务或生产安全已证明。

### 开销与预算

- 调用前持久化 token 和金额预留；超上限不联系模型。工作流内关闭 SDK 隐式重试，失败调用保留预留。
- 调用次数和 token 预留上限可配置；token 按 UTF-8 字节、输出上限及协议余量保守计算，不等同于供应商实际用量。
- SDK 返回的输入、输出、缓存 token 单独保存。未返回的值保持未知。
- 界面可按精确模型名保存输入/输出每百万 token 单价及 CNY/USD，调用保存当时单价快照。缓存输入按统一输入价估算，不推断供应商峰谷优惠或账单扣款。
- 金额预算要求同币种单价；累计调用含未知计价或其他币种时不能验证金额上限。它用于限制新增调用的估算预留，不是供应商扣款硬限额。
- 实时界面展示本次、恢复链累计估算、用量及预算；历史弹窗展示全部已记录估算，继承的恢复账本不重复统计。
- 旧任务缺少用量、调用失败无 usage、或单价未配置时明确未计价，不回填为 0 元。不同币种分开显示。

### 本地交付包

仅交付模式、所有质量门、对应业务场景和人工验收通过的任务可下载 ZIP。包含锁定依赖、源码、清单、测试报告、可用且哈希匹配的截图及运行说明。排除 `.env`、node_modules 和生产数据。

打包前后核对文件指纹，验收后被修改或依赖锁缺失会阻止导出。交付包标记 `local_handoff_not_deployed`，不声称已经上线。服务器、域名、HTTPS、生产数据、正式发布与回滚演练尚需配置并实施。

## 新增接口

| 接口 | 用途 |
|---|---|
| POST `/api/jobs/:id/resume` | 幂等恢复，可选新的累计 limits |
| POST `/api/jobs` | 可选 limits、delivery_mode、business_cases |
| GET/POST `/api/prices` | 查看和保存单模型计价配置 |
| GET `/api/costs` | 跨任务去重的费用估算 |
| GET `/api/jobs/:id/bundle` | 验证后下载本地 ZIP |

接口沿用会话、Host 与写入 Origin 校验。前端校验后端 workflow_version，防止新版界面把交付要求发给会忽略新字段的旧服务。

## 验证证据与限制

自动化覆盖安全检查点、重复恢复、预算前置拦截、未知费用、恢复账本去重、实际 Chromium 保存/刷新、故意丢数据、404 页面、缺少浏览器、交付门阻断、打包篡改检测及 API 权限。真实浏览器场景使用专门的正反例网页，不是客户订单完成证明；模型与构建编排测试使用离线替身，不产生模型费用。

当前未做：多 worker 分布式租约、任意外部系统测试、生产数据库迁移、容器执行沙箱、云发布和订单收款。模型单价须按实际账户配置；参考 [DeepSeek 官方价格](https://api-docs.deepseek.com/quick_start/pricing/)，不要把新模型单价套到未确认的旧模型别名。
