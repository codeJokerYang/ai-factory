# SPEC-005：AI Factory 本地可测试控制台

> 状态：已完成  
> 日期：2026-08-15  
> 分支：`feat/ui-quality-baseline`

## 背景

UI 质量基线原先只有静态视觉样例。样例可以验证排版、响应式与焦点样式，但按钮没有业务事件，
也不能观察 AI Factory 的 Planner、Architect、Decomposer 和 Builder 是否真实执行，因此用户无法
从浏览器验证当前项目。

## 用户故事

作为项目负责人，我希望在不配置 API Key 的情况下输入自己的产品想法，并从浏览器运行一次真实
Agent 编排链，以便检查各阶段状态、结构化产物、生成文件和质量报告。

## 功能范围

- [x] 提供本地浏览器控制台与连接状态。
- [x] 支持输入自定义产品想法和三个可点击示例。
- [x] 使用 `MockLLM` 运行真实 Planner、Architect、Decomposer、Gate 1、Builder、Reviewer、Security。
- [x] 展示每个阶段的状态、耗时与摘要。
- [x] 展示产品规格、12 节点 DAG、生成文件和质量报告。
- [x] 提供生成代码复制操作和完整键盘焦点状态。
- [x] 不要求 API Key，不写入 `generated/`，不修改 `.env`。
- [x] 使用结构化 HTTP 错误响应处理空输入、超长输入和非法 JSON。

## 非目标

- 不替代生产 Gate 2，也不自动提交或部署生成项目。
- Mock 输出用于验证编排和界面，不代表真实模型的产品决策质量。
- 首版不提供长任务流式日志；真实 LLM 模式仍通过现有 CLI 运行。

## 验收标准

- 浏览器可以提交自定义想法并得到七阶段完成结果。
- 返回产物来自项目中的真实 Agent 类，而非前端硬编码的成功动画。
- 空输入、超过 500 字符和非法 JSON 返回明确错误。
- 桌面与 390px 移动端无横向页面溢出。
- 键盘可以操作示例、提交按钮、产物标签和复制按钮。
- 单元、HTTP 集成和边界测试全部通过。
